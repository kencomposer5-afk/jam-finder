# セッションマップ運営者への連絡文案(X: @okoge_enso)

はじめまして。首都圏のジャズ/ブルースのセッション(演奏参加できるもの)を一覧するPWAアプリ「Jam Finder」を個人で作っています。
セッションマップさんの会場・日程データがとても充実していて、次のどれかの形でご協力いただけないか、ご相談です。

1. 【リンクのみ】アプリ内に「セッションマップで探す」リンクを置く(すでに設置済みです)
2. 【データ提供】東京・神奈川・埼玉・千葉の会場名と開催ルールを、出典表記つきで当アプリに掲載させていただく
3. 【APIや書き出し】もし公開できる形式があれば、定期的に参照させていただく

無断での取得・転載は行いません。ご都合の良い形、または不可の場合はその旨をお知らせください。
